Project Documentation & Architecture

1. Software Component Inventory Management

SecurSBOM allows comprehensive management of software dependencies across multiple package managers (npm, Maven, PyPI, Golang). Each component maintains a unique Package URL (PURL), license compliance metadata, and versioning to ensure an accurate bill of materials. Your inventory is automatically persisted in browser localStorage.

2. Vulnerability Scanner & CVE Simulation

The integrated vulnerability identification engine cross-references component versions against known CVE advisories (e.g., Log4j, vulnerable lodash/requests versions). It automatically calculates severity metrics (Critical, High, Medium, Low), CVSS scores, and provides precise remediation version guidance. The Patch action upgrades the component to the recommended fixed version.

3. Standards-Compliant SBOM Generation

Generates industry-standard SBOM formats including CycloneDX (JSON/XML v1.4) and SPDX (Tag-Value/JSON v2.3). Fully compliant with NTIA minimum element requirements including creator identifiers, component hierarchy, timestamping, and cryptographic identifiers.

4. Interactive Risk Metrics & Dashboard

Provides real-time visibility into software supply chain risk scores, vulnerable component ratios, and ecosystem breakdowns to empower SecOps teams and software auditors.
